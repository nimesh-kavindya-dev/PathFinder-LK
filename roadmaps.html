Engineering Track 6 Learning Stages

Software Engineer Learning Roadmap

A structured roadmap taking you from foundational computational logic in your 1st university year to full-stack engineering and internship portfolio readiness.

Master core programming syntax, control structures, and Object-Oriented Programming (OOP) principles.

Topics to Study:

  • Variables, primitive data types, memory allocation, operators, and expressions.
  • Control flow: If-else branching, switch statements, for and while loops.
  • Modular programming: Methods/functions, parameters, return types, scope, recursion.
  • Core Object-Oriented Programming (OOP): Classes, objects, encapsulation, inheritance, polymorphism, abstraction.

Important Skills:

Computational Logic OOP Principles Java / Python / C# Debugging

Recommended Learning Order:

  1. Choose one foundational language (Java or Python).
  2. Practice control structures and write mathematical/logical console programs.
  3. Implement OOP models with multiple interacting classes.
Practical Suggestion: Build 3 small console applications: a Student Grade Calculator, a Bank Account Simulation, and a Command-Line Inventory Tracker.

Learn how to store, retrieve, and process data efficiently in memory to solve algorithmic challenges.

Topics to Study:

  • Linear Data Structures: Arrays, Dynamic Arrays, Linked Lists (Singly & Doubly), Stacks, Queues.
  • Non-Linear Data Structures: Hash Tables / Hash Maps, Binary Search Trees (BST), Graph representations.
  • Algorithms: Linear Search, Binary Search, Bubble Sort, Merge Sort, Quick Sort.
  • Asymptotic Analysis: Big O notation (time and space complexity).

Important Skills:

Big O Complexity Hash Maps Binary Search Tree Traversal

Recommended Learning Order:

  1. Study linear structures first (Arrays, Stacks, Queues).
  2. Master Hash Maps and understand hash collisions and constant-time lookup.
  3. Learn recursive algorithms and binary search.
  4. Analyze time complexity using Big O.
Practical Suggestion: Solve 25–30 beginner problems on LeetCode or HackerRank focusing on Two Sum, Valid Parentheses, and Array manipulation.

Construct modern, accessible, and responsive user interfaces using foundational web technologies.

Topics to Study:

  • Semantic HTML5: header, nav, main, section, article, footer, forms, tables, accessibility attributes (ARIA).
  • Modern CSS3: Box model, Flexbox layouts, CSS Grid, custom properties (variables), media queries for mobile-first design.
  • Vanilla JavaScript (ES6+): DOM manipulation, event listeners, array methods (map, filter, reduce), promises, Fetch API, async/await.
  • Web Accessibility: Color contrast, keyboard navigation, and semantic landmarks.

Important Skills:

Semantic HTML5 Flexbox & CSS Grid Vanilla JS DOM Fetch API

Recommended Learning Order:

  1. Build static semantic HTML pages.
  2. Style layouts with CSS Flexbox, Grid, and mobile media queries.
  3. Add client-side interactivity and form validation with Vanilla JavaScript.
  4. Fetch and render dynamic data from public REST APIs.
Practical Suggestion: Build a responsive web application (like this PathFinder LK platform or a Weather Dashboard) that pulls live data from an open API.

Design, query, and manage persistent data storage systems for modern applications.

Topics to Study:

  • Relational Database Management Systems (PostgreSQL, MySQL).
  • SQL fundamentals: DDL (CREATE, ALTER), DML (INSERT, UPDATE, DELETE), and DQL (SELECT, WHERE, ORDER BY).
  • Relational concepts: Primary keys, foreign keys, cardinality (1:1, 1:N, N:M), multi-table joins.
  • Database Normalization: 1NF, 2NF, 3NF to eliminate data redundancy.
  • Transactions (ACID properties), basic indexing, and an introduction to NoSQL (MongoDB).

Important Skills:

SQL Queries ER Diagramming Schema Normalization PostgreSQL / MySQL

Recommended Learning Order:

  1. Draw Entity-Relationship (ER) diagrams from requirements.
  2. Create database tables with appropriate constraints.
  3. Master multi-table INNER and LEFT joins.
  4. Connect databases to your programming code using JDBC, Prisma, or Hibernate.
Practical Suggestion: Design a relational schema for a university library management system with books, students, loans, and fines.

Connect frontend interfaces, backend APIs, and database persistence into full-stack software applications.

Topics to Study:

  • Backend development frameworks: Java Spring Boot, Node.js/Express, or Python Django/FastAPI.
  • RESTful API design: Endpoints, HTTP methods (GET, POST, PUT, DELETE), JSON payloads, HTTP status codes.
  • User Authentication: Password hashing (BCrypt), JSON Web Tokens (JWT), session security.
  • Frontend frameworks: React components, state, hooks, and routing.
  • Automated Unit Testing: Writing unit tests for controllers and service layers.

Important Skills:

Full-Stack Integration REST APIs JWT Authentication React / Spring Boot

Recommended Learning Order:

  1. Build and test a standalone CRUD REST API with Postman.
  2. Implement secure JWT user login and registration.
  3. Connect the backend API to a responsive React or JavaScript frontend.
Practical Suggestion: Develop a Task & Issue Tracking system with user registration, roles (Admin/Member), status boards, and comment threads.

Package your engineering work, document your projects, and prepare for competitive university internships.

Topics to Study:

  • Advanced Git & GitHub: Feature branching, pull request reviews, resolving merge conflicts.
  • Documentation standards: Writing clean README.md files with project architecture diagrams, setup steps, and screenshots.
  • Deployment & Hosting: Hosting static frontends on GitHub Pages or Vercel; deploying backend APIs to cloud containers.
  • Containerization basics: Writing Dockerfiles to containerize applications.
  • Technical CV & Interview prep: Preparing for technical coding tests and system explanation questions.

Important Skills:

GitHub Portfolio Docker Basics CI/CD & Deployment Interview Readiness

Recommended Learning Order:

  1. Select your top 2 full-stack projects and clean up the code.
  2. Add comprehensive README files with live demo links.
  3. Publish a personal developer portfolio site showcasing your projects.
  4. Practice whiteboard and LeetCode algorithmic interview problems.
Practical Suggestion: Create a polished GitHub profile with pinned repositories, well-formatted READMEs, and apply for 3rd-year university internship positions.

Analytics Track 6 Learning Stages

Data Analyst Learning Roadmap

Progress steadily from spreadsheet data modeling and SQL querying to interactive Power BI dashboards, statistical storytelling, and business portfolio development.

Master spreadsheet computation, formula logic, and data structuring in Microsoft Excel.

Topics to Study:

  • Core formula syntax, cell references (relative vs. absolute), data validation rules.
  • Lookup and conditional functions: XLOOKUP, INDEX/MATCH, VLOOKUP, IF, SUMIFS, COUNTIFS.
  • Pivot Tables & Pivot Charts: Multi-dimensional aggregation, calculated fields, slicers.
  • Data cleaning techniques: Removing duplicate rows, text-to-columns, handling missing cells.

Important Skills:

Advanced Excel Pivot Tables XLOOKUP Data Cleaning
Practical Suggestion: Download a retail transaction spreadsheet and build an automated monthly executive sales summary with interactive slicers.

Learn to extract, filter, join, and aggregate enterprise data stored in relational database engines.

Topics to Study:

  • SQL query clauses: SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.
  • Relational table joins: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN.
  • Aggregate statistical functions: COUNT, SUM, AVG, MIN, MAX.
  • Advanced SQL: Subqueries, Common Table Expressions (CTEs), and Window Functions (ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD).

Important Skills:

SQL Joins Window Functions CTEs PostgreSQL / SSMS
Practical Suggestion: Complete all SQLBolt tutorials and write complex SQL queries to calculate monthly customer retention rates from a database.

Construct professional, interactive visual dashboards using Microsoft Power BI or Tableau.

Topics to Study:

  • Power BI data importing and transformation workflows using Power Query.
  • Data modeling: Star schema, Snowflake schema, primary-to-foreign key relationships, cardinality.
  • DAX (Data Analysis Expressions): CALCULATE, FILTER, RELATED, time-intelligence calculations (Year-over-Year growth).
  • Visual design principles: Choosing between bar, line, scatter, card, and map charts.

Important Skills:

Microsoft Power BI DAX Measures Data Modeling Tableau
Practical Suggestion: Build an interactive Power BI dashboard tracking Sri Lankan university enrollment trends or public healthcare metrics.

Utilize Python libraries for programmatic data manipulation, exploratory data analysis, and statistical visualization.

Topics to Study:

  • Jupyter Notebook workflow and Python data structures (lists, dictionaries, sets).
  • Pandas library: Dataframe indexing, filtering, grouping, merging, pivot tables, handling missing values.
  • NumPy library: Numerical arrays, vectorization, and mathematical operations.
  • Visualization libraries: Matplotlib and Seaborn (histograms, box plots, correlation heatmaps).

Important Skills:

Python (Pandas) NumPy Exploratory Analysis (EDA) Seaborn Charts
Practical Suggestion: Download an open Kaggle dataset (e.g. World Bank development indicators) and create an annotated Jupyter Notebook detailing 5 key statistical findings.

Learn how to connect data findings directly to executive commercial strategies and decision-making.

Topics to Study:

  • Core business metrics: Customer Acquisition Cost (CAC), Churn Rate, Lifetime Value (LTV), Return on Investment (ROI).
  • Statistical testing: Hypothesis formulation, p-values, A/B testing principles, confidence intervals.
  • Data storytelling: Structuring presentations with a clear problem context, empirical findings, and actionable recommendations.
  • Executive summary drafting for non-technical stakeholders.

Important Skills:

Business KPIs Data Storytelling A/B Testing Executive Reporting
Practical Suggestion: Write a 2-page executive business recommendation brief based on your exploratory data analysis, outlining 3 strategic commercial actions.

Curate your best projects, publish interactive dashboards, and prepare for university internship interviews.

Topics to Study:

  • Publishing interactive reports to NovyPro or Tableau Public for public viewing.
  • Documenting SQL queries and Python code in clean, well-annotated GitHub repositories.
  • Kaggle community participation: Sharing notebooks and earning peer upvotes.
  • Interview readiness: Explaining complex SQL window functions and dashboard design decisions during interviews.

Important Skills:

Portfolio Curation Tableau Public GitHub Documentation Internship Interview Prep
Practical Suggestion: Package 3 distinct case studies (one in SQL, one in Power BI, and one in Python) and link them on your LinkedIn profile and CV.

Big Data Track 6 Learning Stages

Data Engineer Learning Roadmap

Learn to architect resilient data architectures, automate high-throughput ETL pipelines, manage cloud warehouses, and process distributed big data streams.

Establish fluency in command-line scripting and backend Python programming for data automation.

Topics to Study:

  • Python programming: File I/O, JSON and CSV parsing, handling exceptions, virtual environments.
  • Linux operating system basics: Navigating the terminal, file permissions, pipes (`|`), `grep`, `awk`, `sed`.
  • Automating cron jobs and writing bash shell scripts.
  • Version control workflows using Git and GitHub.

Important Skills:

Python Scripting Linux / Bash Cron Automation File Parsing
Practical Suggestion: Write a bash script that pulls hourly server logs, extracts HTTP 500 error counts, and logs them to a CSV report.

Master analytical schema design and high-performance querying for data warehousing.

Topics to Study:

  • Differences between OLTP (Transactional) and OLAP (Analytical) database architectures.
  • Dimensional Modeling: Star schema, Snowflake schema, Fact tables, Dimension tables.
  • Advanced SQL: Query optimization, table partitioning, clustering keys, index structures (B-Tree).
  • NoSQL database systems: Document stores (MongoDB) and column-family stores (Cassandra).

Important Skills:

Dimensional Modeling OLAP Architectures Partitioning PostgreSQL / NoSQL
Practical Suggestion: Design a dimensional data warehouse schema for a ride-sharing service featuring fact trips and dimension drivers, riders, and locations.

Construct modern cloud data lakes and query columnar storage formats at scale.

Topics to Study:

  • Cloud object storage architectures: Amazon Web Services (AWS) S3, Google Cloud Storage.
  • Columnar storage file formats: Apache Parquet, ORC, Avro vs. row-based CSV/JSON.
  • Cloud Data Warehouses: Snowflake, Google BigQuery, AWS Redshift.
  • Staging and loading data: COPY INTO commands, external tables, data lake partitioning.

Important Skills:

Snowflake / BigQuery AWS S3 Parquet Storage Data Lakes
Practical Suggestion: Use a free-tier Snowflake or BigQuery account to stage Parquet datasets and measure query execution speed versus uncompressed CSV files.

Build and schedule automated extraction, transformation, and loading pipelines.

Topics to Study:

  • ETL (Extract, Transform, Load) vs. modern ELT (Extract, Load, Transform) paradigms.
  • Workflow orchestration with Apache Airflow: Defining DAGs (Directed Acyclic Graphs), operators, task dependencies.
  • Data transformation with dbt (data build tool): Modular SQL transformations and automated testing.
  • Idempotency, pipeline error handling, alert mechanisms, and backfilling.

Important Skills:

Apache Airflow ETL / ELT Pipelines dbt (Data Build Tool) DAG Scheduling
Practical Suggestion: Build an Apache Airflow pipeline that fetches currency exchange rates from an open REST API daily, cleans the data, and writes it to a PostgreSQL database.

Process terabyte-scale datasets and real-time streaming architectures using distributed computing.

Topics to Study:

  • Distributed computing foundations: Master-worker architectures, parallel execution, partition skew.
  • Apache Spark & PySpark: SparkSession, DataFrames, transformations vs. actions, broadcast joins.
  • Streaming architectures: Introduction to Apache Kafka, topics, producers, consumers, message brokers.
  • Delta Lake and data lakehouse concepts (ACID transactions on object storage).

Important Skills:

Apache Spark (PySpark) Distributed Computing Apache Kafka Data Streaming
Practical Suggestion: Write a PySpark batch transformation script that processes multi-gigabyte server logs to calculate hourly unique visitors and top requested URLs.

Deploy a containerized end-to-end cloud pipeline, write architecture diagrams, and prepare for industry recruitment.

Topics to Study:

  • Containerizing pipeline services with Docker and Docker Compose (Airflow + Postgres).
  • Automated data quality testing using frameworks like Great Expectations.
  • Documenting end-to-end data pipeline architectures with system flowcharts.
  • Publishing clean, reproducible pipeline repositories on GitHub for internship recruiters.

Important Skills:

Docker Compose Architecture Diagrams Data Quality Testing Capstone Portfolio
Practical Suggestion: Build and document an end-to-end pipeline: Ingest API data → Orchestrate in Airflow → Process with Spark → Store in Snowflake warehouse → Visualize in Power BI.

Security Track 6 Learning Stages

Cybersecurity Analyst Learning Roadmap

Progress steadily from network protocol foundations and Linux system hardening to security log inspection, vulnerability assessment, and SOC incident response.

Master how data travels across local and global networks before attempting to defend them.

Topics to Study:

  • The OSI 7-Layer Model and TCP/IP protocol stack.
  • IP Addressing: IPv4, IPv6, Subnetting (CIDR notation), public vs. private IPs, NAT.
  • Essential network protocols: DNS, DHCP, HTTP, HTTPS, SSH, FTP, ARP, ICMP.
  • Network hardware and security perimeters: Routers, switches, firewalls, and VLANs.

Important Skills:

TCP/IP Protocol Subnetting OSI Model DNS & Routing
Practical Suggestion: Use Cisco Packet Tracer to build a virtual campus network topology with subnets, DHCP servers, and access-control lists (ACLs).

Learn operating system architectures, terminal mastery, and secure server configuration.

Topics to Study:

  • Linux operating systems (Ubuntu, Debian, Kali Linux): Navigation, file system hierarchy, package management.
  • Access Control: User accounts, groups, file permissions (`chmod`, `chown`, `umask`), sudo privileges.
  • Process monitoring and system services: `systemctl`, `top`, `ps`, cron jobs, background processes.
  • Windows Server fundamentals: Active Directory, Group Policy Objects (GPO), and NTFS permissions.

Important Skills:

Linux Administration File Permissions System Hardening Active Directory
Practical Suggestion: Play through Levels 0 to 15 of the free OverTheWire Bandit wargame to master Linux commands and SSH security.

Understand the foundational principles of information security and core cryptographic primitives.

Topics to Study:

  • The CIA Triad: Confidentiality, Integrity, and Availability.
  • Authentication & Access: Multi-Factor Authentication (MFA), Principle of Least Privilege, Zero Trust.
  • Cryptography: Symmetric encryption (AES), Asymmetric encryption (RSA), Hashing (SHA-256), Digital Signatures, PKI/Certificates.
  • Attack taxonomy: Phishing, Social Engineering, Malware (Ransomware, Trojans), Man-in-the-Middle (MITM), Denial-of-Service (DDoS).

Important Skills:

CIA Triad Cryptography & Hashing Threat Vectors MFA & PKI
Practical Suggestion: Write a Python script that takes a plaintext string, hashes it with SHA-256 using salt, and verifies password matching.

Inspect real-time network packets, discover active ports, and monitor security event logs.

Topics to Study:

  • Packet analysis using Wireshark: TCP three-way handshake, filtering protocols (`http`, `dns`, `tcp.port`), inspecting payload headers.
  • Network scanning with Nmap: Host discovery, SYN scanning (`-sS`), service version detection (`-sV`), OS fingerprinting (`-O`).
  • Security Information and Event Management (SIEM): Centralized log collection, Splunk / Elastic SIEM fundamentals.
  • Analyzing firewall and authentication failure logs to spot brute-force attempts.

Important Skills:

Wireshark Analysis Nmap Port Scanning SIEM Tools (Splunk) Log Triage
Practical Suggestion: Capture Wireshark network traffic during an unencrypted HTTP login vs. an HTTPS login to visually observe payload encryption.

Identify, evaluate, and report security vulnerabilities across web applications and server perimeters.

Topics to Study:

  • The OWASP Top 10 Web Application Vulnerabilities: SQL Injection, Cross-Site Scripting (XSS), Broken Access Control, Security Misconfiguration.
  • Intercepting web proxy tools: Burp Suite (repeater, proxy, spidering).
  • Vulnerability scanning: Using Nessus or OpenVAS to detect unpatched software versions.
  • Vulnerability scoring: CVSS (Common Vulnerability Scoring System) ratings and remediation recommendations.

Important Skills:

OWASP Top 10 Burp Suite Vulnerability Assessment CVSS Scoring
Practical Suggestion: Complete the free PortSwigger Web Security Academy beginner labs on SQL Injection and reflected XSS in a safe, legal sandbox.

Master the incident containment lifecycle, simulate SOC operations, and prepare for industry defense certifications.

Topics to Study:

  • The NIST Incident Response Lifecycle: Preparation → Detection & Analysis → Containment, Eradication & Recovery → Post-Incident Activity.
  • Security Operations Center (SOC) Tier 1 workflows: Incident triage, ticket documentation, escalation protocols.
  • Hands-on defensive training platforms: TryHackMe (SOC Level 1 pathway) and Blue Team Labs Online.
  • Entry certification alignment: CompTIA Security+, Cisco Certified Support Technician (CCST) Cybersecurity.

Important Skills:

Incident Response SOC Workflows Forensic Triage CompTIA Security+
Practical Suggestion: Complete the free Cisco "Skills for All: Cybersecurity Essentials" modules and document a simulated ransomware response post-mortem report.

Design Track 6 Learning Stages

UI/UX Designer Learning Roadmap

Progress systematically from design thinking and user empathy research to wireframing, accessible design systems in Figma, and complete UX case study portfolios.

Understand the human-centered methodology behind creating intuitive digital products.

Topics to Study:

  • The 5 stages of Design Thinking: Empathize, Define, Ideate, Prototype, Test.
  • Distinguishing User Experience (UX - logic & flows) from User Interface (UI - visuals & aesthetics).
  • Jakob Nielsen's 10 Usability Heuristics for User Interface Design.
  • Cognitive load, Fitts's Law, Hick's Law, and user mental models.

Important Skills:

Design Thinking Usability Heuristics Cognitive Load UX Auditing
Practical Suggestion: Choose a popular Sri Lankan banking or train ticket booking app and conduct a 5-point heuristic usability audit identifying user pain points.

Gather empirical user data, craft user personas, and map out logical information navigation structures.

Topics to Study:

  • User research methods: Qualitative interviews, surveys, competitive analysis.
  • Creating user personas and empathy maps to define user needs, motivations, and frustrations.
  • Customer Journey Mapping: Tracking touchpoints, emotional highs, and pain points across a task.
  • Information Architecture (IA): Organizing app menus, card sorting, and user flow diagrams.

Important Skills:

User Research User Personas Journey Mapping Information Architecture
Practical Suggestion: Interview 3 fellow university undergraduates about challenges finding student study notes, and build a detailed user persona and journey map.

Quickly sketch layout compositions and test navigation flows before investing time in visual styling.

Topics to Study:

  • Paper prototyping and rapid thumbnail sketching.
  • Digital wireframing in Figma: Grids, layout containers, placeholder components.
  • User flow diagramming: Connecting wireframes to simulate button taps and screen transitions.
  • Conducting early feedback sessions on wireframes to validate layout concepts.

Important Skills:

Paper Sketching Figma Wireframing User Flow Diagrams Rapid Prototyping
Practical Suggestion: Sketch a 4-screen wireframe flow for a student carpooling or hostel finder mobile application and link the frames into a clickable low-fidelity prototype.

Master aesthetic principles, typography scales, color harmony, and accessibility standards.

Topics to Study:

  • Typography scales: Font pairings, line heights, font weights, and readability hierarchy.
  • Color theory & psychology: Primary brand colors, neutrals, semantic colors (success, error), 60-30-10 color rule.
  • The 8pt Spacing Grid: Consistent margins, paddings, and alignment rules.
  • Web Content Accessibility Guidelines (WCAG 2.1 AA): Contrast ratios (minimum 4.5:1), touch target sizes (min 44x44px).

Important Skills:

Typography Scales 8pt Grid System Color Psychology WCAG Accessibility
Practical Suggestion: Re-design an existing unstyled web form into a high-contrast, accessible visual interface in Figma adhering strictly to the 8pt grid.

Build scalable design systems and realistic interactive prototypes with smart animations in Figma.

Topics to Study:

  • Advanced Figma Auto-Layout: Responsive resizing, padding, spacing, nested flex-like containers.
  • Component Architecture: Master components, instances, variants, component properties.
  • Interactive Prototyping: Micro-interactions, hover states, overlays, Smart Animate transitions.
  • Design Tokens: Centralized color, typography, and spacing variables for design systems.

Important Skills:

Figma Auto-Layout Design Systems Component Variants Smart Animate
Practical Suggestion: Create a mini design system in Figma with buttons (default, hover, disabled), input boxes, and cards, then assemble a 5-screen clickable prototype.

Validate your designs with real users, prepare specs for developers, and publish polished UX case studies.

Topics to Study:

  • Usability testing protocols: Writing task scenarios, moderated vs. unmoderated tests, gathering qualitative feedback.
  • Design iteration: Refining designs based on observed user friction and testing metrics.
  • Developer handoff: Figma Dev Mode, inspecting CSS, exporting assets, creating component specification notes.
  • Structuring UX Case Studies: Problem statement → User research → Wireframes → Final Prototype → Usability results → Key learnings.

Important Skills:

Usability Testing Developer Handoff Case Study Writing Behance / Notion Portfolio
Practical Suggestion: Write a comprehensive UX case study documenting your entire project journey from initial research to final interactive prototype and publish it on Behance or Notion.
