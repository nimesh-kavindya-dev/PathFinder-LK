Development & Architecture

1. Software Engineer

Building robust, scalable, and maintainable software applications for web, mobile, and enterprise environments.

1. Career Introduction

Software Engineering represents the systematic application of engineering principles, computational logic, and design patterns to the creation of software systems. In Sri Lanka, the software engineering sector forms the largest portion of the ICT export industry, servicing international clients in North America, Europe, Australia, and Asia across domains such as financial services, telecommunications, travel, and healthcare.

2. Job Role

A Software Engineer transforms business specifications and user stories into functioning, secure, and bug-free code. Working as part of an agile software engineering sprint team, they collaborate directly with quality assurance (QA) engineers, UI/UX designers, tech leads, and product owners to design, implement, test, and release digital features.

3. Main Responsibilities

  • Writing clean, efficient, and well-commented code following established object-oriented and functional paradigms.
  • Designing and consuming RESTful and GraphQL APIs for front-end and microservice communication.
  • Participating actively in agile ceremonies: daily stand-ups, sprint planning, and retrospective meetings.
  • Conducting thorough peer code reviews to maintain code quality and prevent software regressions.
  • Writing automated unit and integration tests using frameworks like JUnit, Jest, or PyTest.
  • Diagnosing, debugging, and resolving software defects reported in testing and production environments.
  • Managing source code branches, resolving merge conflicts, and participating in CI/CD deployment pipelines.

4. Required Technical Skills

Programming & Paradigms

Solid grasp of Object-Oriented Programming (OOP), Data Structures (arrays, trees, graphs), and Algorithm Complexity (Big O notation).

Web Foundations & APIs

HTTP protocol, status codes, REST architecture, JSON serialization, client-server communication, and state management.

Databases & Storage

Relational schema design, writing complex SQL queries (joins, indexing), ORMs (Hibernate, Prisma), and basic NoSQL concepts.

5. Required Soft Skills

  • Analytical Problem-Solving: Breaking complex business requirements into smaller, logically sound algorithmic steps.
  • Collaborative Communication: Explaining technical decisions clearly to non-technical stakeholders and receiving feedback productively.
  • Continuous Learning Mindset: Eagerness to explore modern frameworks, libraries, and best practices as industry tooling updates.
  • Attention to Detail: Thoroughness in catching edge cases, validating user inputs, and writing reliable code.

6. Common Tools and Technologies

Java (Spring Boot) JavaScript / TypeScript Python (Django / FastAPI) C# (.NET Core) React.js Node.js / Express PostgreSQL / MySQL Git / GitHub Docker Postman VS Code / IntelliJ IDEA

7. Educational Background or Learning Path

University Background: Bachelor's degree in Software Engineering, Computer Science, Information Systems (IS), or Information Technology (IT) from state or private universities in Sri Lanka.

Key Academic Modules: Object-Oriented Programming (OOP), Data Structures and Algorithms (DSA), Database Management Systems (DBMS), Web Application Development, Software Architecture & Design.

Practical Milestone: Constructing 2–3 full-stack capstone projects during your university studies and committing clean code with documentation to your public GitHub profile.

8. Career Opportunities

Software engineering graduates enjoy widespread employment opportunities across local tier-1 software exporters, banking technology divisions, international remote tech firms, and local tech startups.

Long-term Career Ladder:
Trainee / Intern → Associate Software Engineer (ASE) → Software Engineer (SE) → Senior Software Engineer (SSE) → Technical Lead → Solutions Architect or Engineering Manager.

9. Entry-Level Job Opportunities

  • Software Engineering Intern: Standard 6-month placement undertaken in the 3rd year of university degrees.
  • Trainee Software Engineer: Fast-track development programs for fresh university graduates.
  • Associate Software Engineer (ASE): Core entry-level position responsible for building production features under mentorship.
  • Junior Frontend / Backend Developer: Specialized entry roles focusing specifically on user interfaces or backend microservices.

Business Intelligence & Analytics

2. Data Analyst

Translating organizational data into actionable business intelligence, interactive dashboards, and strategic growth insights.

1. Career Introduction

Data Analysis is the practice of inspecting, cleansing, transforming, and modeling data to discover useful patterns, inform conclusions, and support business decision-making. In Sri Lanka, organizations across banking, telecommunications, retail, and FMCG sectors rely on Data Analysts to understand market demands, track KPIs, and identify operational bottlenecks.

2. Job Role

A Data Analyst acts as the bridge between technical database architectures and non-technical business managers. They query databases, build intuitive visual dashboards, evaluate historical trends, and prepare concise reports that guide leadership decisions.

3. Main Responsibilities

  • Writing efficient SQL queries to extract, filter, join, and aggregate transactional datasets from enterprise databases.
  • Cleaning, validating, and preprocessing messy raw datasets to remove errors, anomalies, and duplicates.
  • Designing interactive visual reporting dashboards in Microsoft Power BI, Tableau, or Google Looker Studio.
  • Calculating key performance indicators (KPIs) and performing trend and cohort analyses.
  • Conducting exploratory data analysis (EDA) using Python libraries to spot statistical correlations.
  • Presenting visual findings in clear, non-technical language to management and department heads.
  • Automating weekly and monthly reporting processes to eliminate manual spreadsheet maintenance.

4. Required Technical Skills

Advanced Relational SQL

Mastery of multi-table joins, subqueries, grouping, aggregate functions, and window functions (RANK, ROW_NUMBER).

Data Visualization & BI

Designing clean dashboards in Power BI or Tableau; DAX measures, data modeling, and relationship cardinality.

Statistics & Scripting

Descriptive statistics (variance, correlation, standard deviation), and data wrangling using Python (Pandas, NumPy).

5. Required Soft Skills

  • Data Storytelling: Ability to explain what the numbers mean in practical, commercial terms rather than technical jargon.
  • Commercial Curiosity: Asking the right questions about why business numbers rise or fall.
  • Meticulous Accuracy: Verifying data integrity so that company decisions are based on verified facts.
  • Effective Presentation: Presenting dashboard insights confidently to diverse teams.

6. Common Tools and Technologies

Microsoft Power BI SQL (PostgreSQL / MSSQL) Advanced Microsoft Excel (VLOOKUP, Pivot) Tableau Python (Pandas, NumPy, Matplotlib) Jupyter Notebooks Google Looker Studio

7. Educational Background or Learning Path

University Background: Degree in Information Systems (IS), Business Information Technology (BIT), Statistics, Data Science, or Computer Science.

Key Academic Modules: Database Management Systems (DBMS), Business Statistics, Business Intelligence, Data Mining, and Quantitative Research Methods.

Practical Milestone: Completing public dataset analyses (e.g. Sri Lankan trade or tourism statistics) on Kaggle and sharing interactive Power BI reports.

8. Career Opportunities

Strong demand across commercial banks, digital payment networks, telecommunications operators, logistics providers, and IT consultancies.

Long-term Career Ladder:
Data Analyst Intern → Junior Data / BI Analyst → Data Analyst → Senior Data Analyst → Business Intelligence Lead → Head of Analytics.

9. Entry-Level Job Opportunities

  • Data Analyst Intern: Assisting senior analysts with query extraction, spreadsheet verification, and report formatting.
  • Junior Business Intelligence Analyst: Designing routine KPI dashboards and validating source database feeds.
  • MIS / Reporting Trainee: Managing scheduled company operational reports in enterprise environments.

Big Data & Pipelines

3. Data Engineer

Designing, building, and maintaining automated data pipelines, cloud warehouses, and big data infrastructure.

1. Career Introduction

Data Engineering is the discipline responsible for constructing the foundational data plumbing that organizations depend upon. Before a Data Analyst can visualize numbers or a Machine Learning model can be trained, Data Engineers must build scalable, fault-tolerant pipelines that collect, clean, and organize millions of data records from diverse source systems.

2. Job Role

A Data Engineer builds and manages automated data extraction, transformation, and loading (ETL/ELT) workflows. They ensure that high volumes of real-time and batch data flow seamlessly into centralized cloud data warehouses while upholding strict data quality, governance, and security standards.

3. Main Responsibilities

  • Architecting, developing, and operating automated ETL/ELT pipelines using Apache Airflow and Python.
  • Designing optimized data models (Star and Snowflake schemas) for cloud warehouses like Snowflake or BigQuery.
  • Writing distributed computing transformations using Apache Spark and PySpark.
  • Converting unstructured and semi-structured data (JSON, CSV, logs) into optimized columnar formats (Parquet).
  • Monitoring pipeline latency, failure rates, and resource utilization to prevent processing downtime.
  • Implementing data validation tests and quality checks within pipeline transformations.
  • Collaborating with software engineers to ingest transactional database changes via Change Data Capture (CDC).

4. Required Technical Skills

Pipeline Programming

Proficiency in Python, SQL, or Scala for writing data extraction scripts and pipeline orchestrations.

Distributed Computing & ETL

Knowledge of Apache Spark, PySpark, Airflow DAGs, batch processing vs. stream processing.

Cloud Data Warehousing

Dimensional modeling, partitioning, clustering, and storage schemas in Snowflake, BigQuery, or Redshift.

5. Required Soft Skills

  • Systems-Level Thinking: Envisioning end-to-end data flows, bandwidth constraints, and potential failure points.
  • Patience & Root-Cause Debugging: Systematically tracking down silent data corruptions or pipeline schema mismatches.
  • Cross-Team Coordination: Collaborating with data analysts to understand reporting schema requirements.

6. Common Tools and Technologies

Python (PySpark) SQL Apache Airflow Apache Spark Snowflake Google BigQuery AWS (S3, Glue, Athena) Docker Linux / Bash Git

7. Educational Background or Learning Path

University Background: Degree in Computer Science, Software Engineering, Information Technology, or Data Science.

Key Academic Modules: Advanced Database Management, Operating Systems, Distributed Systems, Cloud Computing, Algorithm Design.

Practical Milestone: Constructing an end-to-end automated data pipeline that pulls data from an open web API, transforms it in Python, and loads it into a cloud database.

8. Career Opportunities

Surging demand as Sri Lankan tech enterprises expand their cloud infrastructure and international clients migrate legacy databases to modern cloud architectures.

Long-term Career Ladder:
Data Engineering Intern → Associate Data Engineer → Data Engineer → Senior Data Engineer → Lead Data Architect.

9. Entry-Level Job Opportunities

  • Data Engineering Intern: Assisting with pipeline maintenance, SQL query optimization, and documentation.
  • Associate Data Engineer: Building supervised pipeline components and writing transformation scripts.
  • Junior Database / ETL Developer: Managing database migrations and routine data loads.

Security & Defense

4. Cybersecurity Analyst

Protecting corporate networks, digital systems, and confidential information from unauthorized access, cyber threats, and attacks.

1. Career Introduction

Cybersecurity is the discipline focused on protecting digital systems, networks, devices, and sensitive organizational data from unauthorized intrusion, theft, or sabotage. In Sri Lanka, the rapid growth of online banking, fintech platforms, government e-services, and cloud systems has made cybersecurity a critical national and commercial necessity.

2. Job Role

A Cybersecurity Analyst (often serving in a Security Operations Center - SOC) acts as a front-line defender. They monitor network traffic, evaluate security alerts, patch discovered vulnerabilities, enforce security protocols, and respond immediately to suspected security incidents.

3. Main Responsibilities

  • Monitoring real-time network traffic and security event logs using SIEM software (Splunk, Elastic).
  • Triage and investigating security alerts to determine whether an activity is a false positive or an actual threat.
  • Conducting vulnerability scans on servers, web applications, and network devices using tools like Nessus or Nmap.
  • Assisting with incident response when malware, ransomware, or unauthorized intrusions occur.
  • Configuring and auditing firewalls, VPNs, and Endpoint Detection and Response (EDR) agents.
  • Analyzing phishing email reports and inspecting suspicious file attachments in sandboxed environments.
  • Drafting comprehensive incident post-mortem reports and conducting employee security awareness briefings.

4. Required Technical Skills

Networking Protocols

Deep knowledge of the OSI model, TCP/IP, IP addressing, DNS, DHCP, SSL/TLS, and subnetting.

Operating System Hardening

Proficiency in Linux terminal commands, permissions, Windows active directory, and security auditing.

Threat & Attack Knowledge

Understanding OWASP Top 10 web vulnerabilities (SQLi, XSS, CSRF), malware types, and MITRE ATT&CK framework.

5. Required Soft Skills

  • High Integrity & Discretion: Strict ethical conduct when handling sensitive access credentials and corporate data.
  • Inquisitive Mindset: Thinking like an attacker to discover subtle weaknesses in existing defense mechanisms.
  • Composure Under Pressure: Staying calm, methodical, and disciplined during high-stress security incidents.
  • Detailed Documentation: Writing clear, factual technical incident reports for executive management.

6. Common Tools and Technologies

Wireshark (Packet Analysis) Nmap (Network Scanner) SIEM (Splunk / Elastic) Linux (Ubuntu / Kali) Burp Suite Metasploit Basics Nessus Python Scripting Bash Scripting

7. Educational Background or Learning Path

University Background: Degree in Cybersecurity, Computer Networks, Information Technology (IT), or Computer Science.

Key Academic Modules: Computer Networks, Network Security, Operating Systems, Cryptography, Information Assurance, System Administration.

Practical Milestone: Completing hands-on security wargames (OverTheWire Bandit), TryHackMe pathways, or obtaining foundational certifications (CompTIA Security+).

8. Career Opportunities

High-demand career tracks across commercial banks, telecom operators, security consultancies, managed security service providers (MSSPs), and national defense bodies like Sri Lanka CERT.

Long-term Career Ladder:
SOC Analyst Tier 1 → SOC Analyst Tier 2 / Incident Responder → Senior Security Engineer → Penetration Tester / Consultant → Chief Information Security Officer (CISO).

9. Entry-Level Job Opportunities

  • SOC Analyst Tier 1 (Trainee): Frontline monitoring of SIEM security events and initial ticket escalation.
  • Information Security Intern: Assisting in vulnerability scanning, policy documentation, and phishing awareness drills.
  • Junior Network Security Associate: Assisting in firewall maintenance and basic network audits.

Human-Computer Interaction & Design

5. UI/UX Designer

Crafting intuitive user experiences, wireframes, accessible design systems, and beautiful digital product prototypes.

1. Career Introduction

UI/UX Design unites human psychology, user research, and visual aesthetics to create digital products that are intuitive, easy to navigate, and satisfying to use. In Sri Lanka’s software export sector, companies increasingly differentiate themselves by delivering world-class user experiences rather than just functional software code.

2. Job Role

A UI/UX Designer investigates how users interact with technology (UX - User Experience) and designs the digital screens, buttons, navigation flows, and visual styling (UI - User Interface). They translate business requirements into wireframes, clickable prototypes, and design systems for frontend developers to construct.

3. Main Responsibilities

  • Conducting user research through interviews, surveys, card sorting, and competitive analysis.
  • Synthesizing research into user personas, empathy maps, and user journey maps.
  • Creating information architecture, site maps, and low-fidelity paper and digital wireframes.
  • Designing high-fidelity interactive, clickable prototypes in Figma for desktop, tablet, and mobile views.
  • Building and maintaining reusable design systems (typography scales, color palettes, accessible component libraries).
  • Conducting usability testing sessions with real users to identify design friction points.
  • Collaborating closely with frontend developers to ensure design accuracy and responsive implementation.

4. Required Technical Skills

Industry Design Tools

Advanced Figma proficiency: auto-layout, components, variants, interactive prototyping, and design libraries.

UX Research & Evaluation

Heuristic evaluation, usability testing protocols, user journey mapping, and information architecture.

Web Accessibility (WCAG)

Color contrast ratios, readable typography, responsive layouts, and basic familiarity with HTML5 & CSS3.

5. Required Soft Skills

  • Empathy: Stepping outside personal preferences to understand the frustrations and needs of diverse users.
  • Receptiveness to Feedback: Iterating designs positively based on usability testing and stakeholder critiques.
  • Visual Communication: Articulating the clear design rationale behind layouts, button placements, and typography.
  • Cross-Functional Teamwork: Working side-by-side with frontend developers and product owners.

6. Common Tools and Technologies

Figma (Auto-layout & Prototyping) FigJam / Miro (Brainstorming) Adobe XD HTML5 & CSS3 Basics Maze (Usability Testing) Notion (Documentation)

7. Educational Background or Learning Path

University Background: Degree in Information Systems, Human-Computer Interaction (HCI), Computer Science, Multimedia Design, or IT.

Key Academic Modules: Human-Computer Interaction (HCI), Usability Engineering, Web Design & Development, Multimedia Systems.

Practical Milestone: Producing 2 in-depth UI/UX case studies documenting the complete design thinking process (research $\rightarrow$ wireframing $\rightarrow$ Figma prototype $\rightarrow$ usability test results).

8. Career Opportunities

High demand across software product development companies, digital agencies, fintech platforms, and remote global product teams.

Long-term Career Ladder:
UI/UX Design Intern → Associate UI/UX Designer → UI/UX Designer → Senior Product Designer → Lead UX Researcher / UX Architect → Head of Design.

9. Entry-Level Job Opportunities

  • UI/UX Design Intern: Assisting design teams with icon preparation, wireframes, and usability test transcription.
  • Associate UI/UX Designer: Designing feature screens, maintaining component variants in Figma, and conducting user tests.
  • Junior Product Designer: Working on end-to-end mobile and web interfaces under senior guidance.
